# 53 — Typer une fonction

**Notion :** types primitifs, paramètres, retour  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Écrivez un type pour chaque paramètre et pour le retour de total(prix, quantite). Affichez 30 pour 10 et 3.

## Lancer

Lancez `npm install`, `npm run build`, puis `npm start`.

## Vérifier

30

## Comprendre

Les paramètres et le retour sont explicitement numériques. Le compilateur refuserait un appel avec des chaînes.
