# 36 — Afficher un panneau

**Notion :** classList, aria-expanded  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Alternez la visibilité du panneau avec la classe hidden et synchronisez aria-expanded.

## Lancer

Ouvrez index.html par double-clic dans un navigateur.

## Vérifier

Chaque clic ouvre ou ferme le panneau.

## Comprendre

hidden masque le panneau sans classe supplémentaire. aria-expanded renseigne aussi son état pour les technologies d’assistance.
