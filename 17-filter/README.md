# 17 — Filtrer un catalogue

**Notion :** filter  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Créez un nouveau tableau avec les produits en stock et affichez seulement leurs noms.

## Lancer

Lancez `node main.js` depuis ce dossier.

## Vérifier

[ 'A', 'C' ]

## Comprendre

filter conserve les objets dont le stock est positif ; map extrait leurs noms sans modifier les produits originaux.
