# 35 — Activer un bouton

**Notion :** change, checked, disabled  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Le bouton de confirmation n’est utilisable que lorsque la case est cochée.

## Lancer

Ouvrez index.html par double-clic dans un navigateur.

## Vérifier

Le bouton s’active et se désactive avec la case.

## Comprendre

checked est un booléen. La propriété disabled inverse cet état pour contrôler directement le bouton.
