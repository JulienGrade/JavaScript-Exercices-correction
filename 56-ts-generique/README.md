# 56 — Retourner le premier élément

**Notion :** générique et undefined  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Écrivez premier<T>(valeurs: T[]) qui retourne T | undefined, sans perdre le type des éléments.

## Lancer

Lancez `npm install`, `npm run build`, puis `npm start`.

## Vérifier

3

## Comprendre

T reprend le type de chaque élément donné à la fonction. undefined rappelle qu’un tableau peut être vide.
