# 38 — Ajouter aux favoris

**Notion :** événement, Set, DOM  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Un clic sur le bouton ajoute ou retire son identifiant des favoris. Affichez le nombre de favoris.

## Lancer

Ouvrez index.html par double-clic dans un navigateur.

## Vérifier

Les clics font passer le compteur de 0 à 1 puis à 0.

## Comprendre

Set stocke un identifiant au plus une fois. aria-pressed décrit l’état du bouton et size fournit le compteur.
