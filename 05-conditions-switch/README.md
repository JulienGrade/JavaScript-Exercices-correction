# 05 — Choisir un statut de commande

**Notion :** switch et break  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Pour le statut « expédie », affichez « En livraison ». Prévoyez aussi « nouveau », « livré » et un cas par défaut.

## Lancer

Lancez `node main.js` depuis ce dossier.

## Vérifier

En livraison

## Comprendre

Chaque case associe une valeur à un libellé. break évite de poursuivre dans le case suivant ; default couvre les valeurs inconnues.
