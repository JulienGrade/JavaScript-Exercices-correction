# 37 — Trier un catalogue

**Notion :** select, change, sort, DOM  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Triez les trois prix en ordre croissant ou décroissant selon le select, sans modifier le tableau initial.

## Lancer

Ouvrez index.html par double-clic dans un navigateur.

## Vérifier

Croissant : B, C, A ; décroissant : A, C, B.

## Comprendre

Le changement de sélection relance le rendu. Une copie protège les données de départ de sort.
