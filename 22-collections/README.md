# 22 — Supprimer les doublons

**Notion :** Set et Map  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Créez la liste des catégories uniques avec Set puis une Map donnant le nombre d’occurrences de chaque catégorie.

## Lancer

Lancez `node main.js` depuis ce dossier.

## Vérifier

[ 'jeu', 'musique' ] 2

## Comprendre

Set ne conserve qu’un exemplaire de chaque catégorie. Map associe ensuite chaque catégorie à son compteur.
