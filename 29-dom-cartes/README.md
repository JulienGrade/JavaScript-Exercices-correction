# 29 — Rendre des cartes

**Notion :** tableau, filter, DOM  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

N’affichez que les produits ayant du stock, avec un h2 et le prix pour chacun. Prévoir un message si aucun produit ne reste.

## Lancer

Ouvrez index.html par double-clic dans un navigateur.

## Vérifier

Seule la carte « Casque » apparaît.

## Comprendre

Le filtrage précède le rendu. Le code crée les nœuds et traite explicitement le tableau vide.
