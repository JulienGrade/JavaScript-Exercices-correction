# 23 — Créer une carte de jeu

**Notion :** class, constructeur, méthode, this  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Créez une classe Carte avec nom et puissance ; sa méthode decrire retourne « Nom (puissance) ». Instanciez-la.

## Lancer

Lancez `node main.js` depuis ce dossier.

## Vérifier

Éclair (5)

## Comprendre

Le constructeur enregistre les valeurs sur l’instance. this désigne cette instance dans la méthode.
