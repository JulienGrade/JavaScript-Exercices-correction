# 01 — Préparer une fiche produit

**Notion :** const, let, types et interpolation  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Correction et explication

Déclarez un nom, un prix et un stock. Augmentez le stock de 2, puis affichez une phrase avec un template literal.

## Lancer

Lancez `node main.js` depuis ce dossier.

## Vérifier

Casque audio : 39.9 € (6 en stock)

## Comprendre

const garde les valeurs qui ne changent pas ; let permet de modifier le stock. Le template literal insère les trois valeurs dans la phrase.
